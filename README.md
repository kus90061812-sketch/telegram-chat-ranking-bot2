# Telegram Chat Ranking Bot — Web Event Admin

## 핵심 기능
- `.이벤트`: 웹에서 **저장된 현재 이벤트**를 줄바꿈 그대로 출력
- 웹 관리자에서 방별 설정
  - 집계 최소 글자 수 (기본 4)
  - 순위 표시 개수 (기본 10)
  - 이벤트 이모지 / 제목 / 본문
  - 텔레그램 출력 미리보기
- 이벤트 본문의 Enter 줄바꿈을 그대로 유지
- 기존 관리자/제외/일일·주간 순위 기능 유지

## 이벤트 보존 방식
이 버전은 새 이벤트 문구를 코드 기본값으로 미리 넣지 않습니다.

- 배포만 해서는 기존에 저장된 이벤트를 덮어쓰지 않습니다.
- `집계 설정 저장`은 글자 수/순위 개수만 바꾸며 이벤트 내용은 건드리지 않습니다.
- `이벤트 저장`을 눌렀을 때만 이벤트 이모지/제목/본문이 변경됩니다.
- DB에 이미 이벤트가 저장되어 있으면 그대로 표시됩니다.
- DB에 이벤트가 전혀 없으면 `.이벤트`는 `현재 등록된 이벤트가 없습니다.`라고 표시합니다.

따라서 새 이벤트를 특정 시각부터 노출하고 싶다면 그 시각에 웹 관리자에서 이벤트를 저장하면 됩니다.

## 웹 관리자
Railway Variables 예시:

```env
ADMIN_USERNAME=admin
ADMIN_PASSWORD=원하는비밀번호
```

Railway Public Domain으로 접속한 뒤 로그인합니다.

### 채팅 집계 설정
`집계 설정 저장` 버튼으로 저장합니다.
- 이벤트 내용과 완전히 분리되어 있습니다.
- 기본값: 4글자부터 집계 / 1~10위 표시

### 이벤트 설정
`이벤트 저장` 버튼으로 저장합니다.
- 이모지 선택
- 제목 입력
- 본문 입력
- 줄바꿈 미리보기

## 이벤트 입력 예시
원하는 시각에 아래처럼 웹에서 저장할 수 있습니다.

```text
🎲 매주 월요일 6시 바카라 꿍 이벤트

채팅 갯수 2222개 달성 시 참여가능
선착순 5명 (각 2만원씩 지급)
```

## 주요 명령어
- `.이벤트` — 현재 저장된 이벤트 확인
- `.일일순위` — 일일 순위
- `.주간순위` — 주간 순위
- 기존 관리자 명령어 유지

### 현재 기본값 보존
- 채팅 집계 최소 글자 수: **5글자**
- 일반 `.일일순위` / `.주간순위`: **1~4위**
- 웹에서 저장한 뒤에만 변경됩니다.
- 이벤트도 웹에서 `이벤트 저장`을 눌렀을 때만 변경됩니다.

## 웹 관리자 - 주간 순위 하단 안내문구
- 방별로 `.주간순위`, 자동 주간순위, 월요일 최종 확정 순위 하단 문구를 수정할 수 있습니다.
- 기본값은 기존 운영 문구를 그대로 유지합니다.
- `하단 안내문구 저장`을 누른 경우에만 변경됩니다.
- 엔터 줄바꿈은 그대로 반영됩니다.
- `@username` 형식은 텔레그램 프로필 링크로 표시됩니다.
